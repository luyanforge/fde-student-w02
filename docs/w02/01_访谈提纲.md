# W02 访谈提纲（按角色，可直接粘贴）

> 版本：v1｜2026-10-31｜配 `00_待核实问题清单.md` 使用。
> 访谈对象是**教学虚构客户**（青禾优选），访谈服务沿用 W1 个人账号，按班期窗口开放。
> 目标不是"问出答案"，而是**取得可定位的原文**：谁说的、在什么范围、什么时间、附带什么条件。

## 0. 通用纪律（五条，先看再问）

1. **提问不代表对方的主张。**"我问一句'复购率是不是在跌'"不等于他说了在跌。记录时只写他的回答。
2. **"提问 + 不知道"不构成分歧。**双方都说不知道，是共同未知，不是冲突。
3. **先问具体动作，再问看法。**不要一上来问"你怎么看这个项目"，先问"上一次你为了这件事具体做了哪几步"。
4. **不要求对方代写业务模型、不要请他裁定作业。**也不要问"我应该怎么建模"。
5. **不同角色的说法不要互相喂。**交叉核实时先各自独立问，再原话转述并注明"这是转述"。

## 1. 老周（IT 负责人｜必访）

**访谈定位**：W01 的 6 条 unknown 里有 4 条卡在系统与数据侧（GAP-001/002/006/007）。老周是本周边际收益最高的一个角色。

**开场**：我在把上一期项目和这次会员经营的需求理清楚，想先了解你这边系统上实际是怎么跑的，不谈方案。

### 主线问题

- **Q1** 现在会员、订单、门店这三块数据分别存在什么系统里？各自是谁在维护？
- **Q2** 会员表里"会员"是怎么定义的？有没有"注销/黑名单/测试账号"这类要排除的情况？
- **Q3** 订单表里退款怎么记？是单独一张表，还是在订单上标记？（GAP-003 的相关性）
- **Q4** 沈总说"80 万活跃会员"，这个"活跃"在系统里是什么口径？近 30 天有交易，还是近 90 天？这个数从哪个报表出来？（GAP-006）
- **Q5** 复购率有没有成文口径？分子分母分别是什么、统计周期多长、要不要分线上线下？（GAP-001）
- **Q6** 最近四个季度的复购率，有没有现成报表可以直接给我看？（GAP-002）
- **Q7** 上一期那个平台，系统上能查到使用记录吗？按门店或按角色，用的人有多少？（V-04）
- **Q8** 上一期"根据业务反馈持续调整需求"——这些变更有没有记录？大概改了几轮、改动落在哪些模块？（V-02/V-03）
- **Q9** 数据如果要拿出来做分析，是导出 Excel、开只读账号，还是只能在客户环境里跑？脱敏谁定？
- **Q10** 你个人认为上一期最大的问题是什么？依据是什么？

### 追问触发

| 他答 | 追问 |
| --- | --- |
| "有报表" | 能不能给我一份原件？报表名、出数系统、更新频率是什么？ |
| "大概…近 30 天吧" | 这个"大概"是看过配置，还是印象？谁能确认？ |
| "都改过好几轮" | 最近一次改是什么时候、因为谁提的？ |
| "数据不方便出去" | 那能不能在客户环境里跑？谁审批？ |

### 必须争取的材料

会员/订单/门店字段清单（哪怕截图）、复购率报表原件或口径文档、上期系统使用统计、变更记录。

### 记录要点

- 所有口径类回答标"是配置/文档，还是口述印象"。
- 任何数字记下来源（哪个系统、哪个报表、什么时点）。

## 2. 小林（会员运营经理｜必访）

**访谈定位**：判断"可用"的标准在她手里（GAP-004），会员老化与分层需求也只有她能说清（GAP-005）。

**开场**：想了解你现在每天／每月为了会员这件事具体做什么，尤其是手工做的那部分。

### 主线问题

- **Q1** 你现在一周里，跟会员经营相关的重复工作有哪些？各花多少时间？
- **Q2** 最近一次你判断"这批会员需要重点经营"，是怎么挑出来的？用了什么表、什么条件？
- **Q3** 挑出来之后，下一步动作是什么？发给谁、以什么形式发？
- **Q4** 沈总说的"会员老化"，你自己怎么判断一个会员"老了"？看入会时间、消费频次，还是别的？（GAP-005）
- **Q5** 复购率你平时看的是哪个数？跟老周那边系统的数一样吗？（D-1 交叉点）
- **Q6** 如果工具给你一份名单加建议，你什么情况下会说"这个我能直接用"，什么情况下会说"还得我自己再整理一遍"？（GAP-004）
- **Q7** 名单出来到真正触达客户，中间要经过谁？门店会配合吗？（D-2）
- **Q8** 上一期那个平台，你自己用过吗？用在哪一步？后来为什么不用了？（D-3）
- **Q9** 如果建议发出去效果不好，责任怎么算？这个你考虑过吗？
- **Q10** 你希望这次的东西，第一个月就能帮你省掉哪件事？

### 追问触发

| 她答 | 追问 |
| --- | --- |
| "我一般看感觉" | 能不能举一个最近的具体例子：哪几个人、你依据什么判断的？ |
| "门店会配合" | 最近一次是哪个门店、谁接的、结果如何？ |
| "能直接用" | 具体要包含哪几列信息？为什么是这几列？ |
| "不用了" | 是操作太麻烦、结果不准，还是没人要求用？ |

### 记录要点

- "能直接用"的标准要问成清单，不当成一句评价。
- 区分她的**个人判断**与**部门已成型做法**。

## 3. 陈姐（大区门店店长｜必访）

**访谈定位**：W01 的 GAP-011 只有角色定位、没有任何意见。她的回答决定"识别→触达"这一段能不能落地。

**开场**：想了解门店这边跟会员相关的日常工作是怎么安排的，人手和时间上有什么实际限制。

### 主线问题

- **Q1** 你管的片区有几家店、多少店员？会员相关的事在店里由谁做？
- **Q2** 店员一天里跟会员打交道的时间大概占多少？在什么环节（到店、结账、电话、微信）？
- **Q3** 上一次总部或运营给门店下过会员名单或任务吗？是哪个、怎么下的、店里怎么处理的？
- **Q4** 名单落到店里，谁负责联系？有没有话术、有没有记录？联系了没有怎么留痕？
- **Q5** 店里现在用什么工具记录这些？（系统、Excel、微信群、纸质）
- **Q6** 上一期那个平台，你或店员用过吗？卡在哪一步？（D-3）
- **Q7** 如果系统每天给一张"今天该联系谁"的清单，你觉得店里会用吗？什么情况下会不用？
- **Q8** 店员的考核里，会员复购或会员回头有没有占比？
- **Q9** 让店员多点一次确认、多填一栏记录，你能接受吗？底线在哪？
- **Q10** 你个人认为总部那边对门店的实际困难了解吗？依据是什么？

### 追问触发

| 她答 | 追问 |
| --- | --- |
| "会用" | 现在有没有类似的清单在用？如果没有，为什么这次会用？ |
| "没时间" | 一周里哪几天最紧？这件事挤掉的是什么？ |
| "考核里有" | 具体指标名、权重、谁考核？ |
| "不了解" | 有没有具体一次沟通让你这么判断？ |

### 记录要点

- 门店侧的人力约束要用**数字**（人数、时长、频次），不用形容词。
- 她与运营（小林）说法不一致时，先记录双方原话与场景，不当场判定谁对。

## 4. 王经理（财务经理｜选访，建议访）

**访谈定位**：预算、验收口径与"结果怎么算"的话语权在这里。选访不等于可省——若预算与验收口径无法核实，W3 的 SOW 会失去锚点。

**开场**：想了解上一期项目的预算与验收在财务侧是怎么记的，以及这次如果要立指标，财务会看哪几个数。

### 主线问题

- **Q1** 上一期智能营销平台的预算规模与执行情况，财务侧有记录吗？超支还是结余？
- **Q2** 上一期的验收，财务参与了吗？验收依据是什么文件？
- **Q3** 沈总说"上一个项目的预算是我批准的，所以这次我需要更清楚地看到结果"——从财务角度，"看到结果"通常指什么？
- **Q4** 本次如果立项，"会员复购率"作为指标，财务侧认可的计算口径是什么？和运营口径会打架吗？（D-4）
- **Q5** 复购率的基线数值财务有没有独立的一套？（GAP-002）
- **Q6** 项目付款节点通常怎么设？跟验收指标挂钩吗？
- **Q7** 有没有硬性的合规或数据使用要求，是我这边必须提前知道的？
- **Q8** 你个人对这类"提升复购"的项目，通常的怀疑点是什么？

### 记录要点

- 只记录财务侧口径，不承诺任何报价或付款条件。
- 涉及合同与金额的表述一律记"待确认"，不作我方承诺。

## 6. 交叉核实设计（至少落地 1 组）

| 组 | 独立问法（各自先问，不互相喂） | 比对什么 |
| --- | --- | --- |
| D-1 复购率 | 老周：Q5/Q6；小林：Q5；王经理：Q4/Q5 | 分子分母、周期、渠道维度是否同一件事 |
| D-2 名单到触达 | 小林：Q7；陈姐：Q3/Q4 | 谁下、谁接、有无留痕 |
| D-3 上期是否用起来 | 老周：Q7；小林：Q8；陈姐：Q6；沈总：Q1 | 系统数字 vs 一线实操 vs 高层结论 |
| D-4 活跃会员口径 | 老周：Q4；王经理：Q4 | 定义与取数系统 |

**转述纪律**：只有在两方都独立答完后，才可以把 A 的原话转述给 B 求证，并明确说"这是转述，不是我的判断"，同时在记录里标注该轮为交叉验证轮。

## 7. 每场访谈结束后 3 分钟内要做的事

1. 在访谈服务里**导出"提取用记录"**（不要靠手抄）。
2. 存到 `artifacts/w02/sources/`，文件名建议 `role-老周_2026-10-31.md`，不改内容、不加批注（批注写进 `interview_notes.md`）。
3. 只记三行摘要：这场拿到了哪几个新事实 / 哪条与 W01 冲突 / 下一步还要问谁。
