## 5. 验收对齐（照着自查）

| 任务书四问 | 自查口径 |
| --- | --- |
| 访谈是否取得具体有用信息 | 每条重要结论能定位到"会议号 + 消息号"，且有至少一次针对职责的追问 |
| 采用的信息是否有依据、条件是否完整 | 业务模型每条带来源、时间、适用范围、例外；不把推断写成原话 |
| 业务模型是否清楚、能否解释建模选择 | 能对任意三条说出：为什么这样划分对象、错了会改变 W01 哪条判断 |
| Agent 是否实际使用这些认识 | `request.json` 的 `business_model` 字段确有内容；两组回答有**具体**差异（不是措辞更谨慎） |
